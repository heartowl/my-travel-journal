旅行手帳 雲端資料移轉測試版（不是正式自動同步版）

1. 先在 iPhone 現有旅行手帳匯出完整 JSON 備份並另存安全位置。
2. 本 ZIP 解壓後，將檔案上傳到原 GitHub Pages repository。不要刪除 iPhone App 或 Safari 網站資料。
3. 更新後，打開「備份」頁面下方的雲端資料移轉區。填入 Supabase Publishable key、Email、密碼登入。
4. 確認 Supabase 四張表都空白，再按「首次上傳本機資料」。
5. 上傳後請至 Supabase 檢查四張表筆數；不要立即在其他裝置編輯。

限制：不會自動同步；只允許首次空雲端上傳、空本機下載。登入權杖僅保存在本頁記憶體，重整後需重新登入。若上傳中斷，可能部分成功；程式將拒絕再次上傳，需先檢查。
此版本不支援雙向同步、刪除同步、衝突解決或同行者唯讀分享。
